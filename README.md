# BlogWrites

An engaging and educational platform for blogs about animals.

## Ideal User Experience
- The UI should be visually appealing and elegant.
- Yellow should be the predominant color throughout the UI to align with the project's theme.
- Each animal blog should have a dedicated HTML page.
- Cards should be used to represent animals, acting as hyperlinks to their respective blog pages.

## Project Structure
```
backend/
    app.py
    requirements.txt
content/
    blogs/
frontend/
    index.html
    styles.css
spec.md
```
